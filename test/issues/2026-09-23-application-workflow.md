# 2026-09-23：投递辅助流程

- 状态：本地扩展测试通过，待招聘网站实页复验。
- 版本：源码 1.16.0-dev；本轮使用隔离 Chromium 加载临时源码副本，未替换用户日常浏览器中的扩展。
- 来源：本地流程审查与固定演示资料测试，没有对应真实招聘网站 runId。

## 观察与修复

1. 旧版消息未统一指定 frame，嵌入表单页面的执行目标不明确。新增只读区域发现与显式选择，填写、停止、状态和定位消息指定文档或 frame；快捷键遇到多个候选区域时提示使用侧栏选择。
2. 侧栏填写缺少独立的确认阶段。新增只读字段检查；确认时验证资料、控件、值、标签和 URL 未变。SPA 复用相同控件但切换岗位也会使旧检查失效。
3. 切换区域时，旧区域延迟返回的状态或错误可能覆盖新区域提示。增加请求代次校验，丢弃旧响应并释放轮询锁。
4. 新增本地 PDF 文本读取与独立岗位记录。PDF 选择不会调用 AI；岗位信息需核对后收藏，“已投递”需本人确认，不能由填写次数推断。

## 证据与回归范围

- `test/real-extension-workflow.cjs`：实际 MV3 service worker、内容脚本、侧栏和存储；双 iframe 只填选定区域，检查期间零写入、过期检查拒绝、保留既有输入、零提交；岗位信息核对并持久化。
- `test/workflow-races-regression.cjs`：实际运行时函数复现 SPA/History URL 变化及旧 frame 延迟成功/失败响应。
- `test/frame-router-regression.cjs`：并发请求隔离、发送方校验、超时与禁止广播写入。
- `test/applications-regression.cjs --browser`：存储、URL 去重及 SPA 岗位区分、本人确认状态、导出和实际管理页面交互。
- `test/pdf-import-regression.cjs`：真实扩展 CSP 下的中文/英文多页 PDF、本地 worker、无外部请求、错误及资源上限、超时恢复、保留旧资料。
