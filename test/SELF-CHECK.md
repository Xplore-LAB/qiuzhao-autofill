# 真实页面快速自检（v1.12.0）

1. 重新加载扩展并刷新表单页面，使新脚本生效。
2. 确认资料与“覆盖非空字段”设置，点击“填写并自检”。使用演示资料时不要提交真实申请。
3. 自检等待填写后两次回读（800 ms 与额外 400 ms），对填写阶段已确认成功的字段再次检查稳定性，以及原生 validity、aria-invalid 和已识别组件校验提示。
4. 结果分已验证、失败、缺资料、需人工。已有但未覆盖的字段归需人工，不算错误或成功；重新渲染的控件不猜测重绑。
5. 展开逐字段结果，点击条目可滚动定位并高亮；弹窗关闭后可点“查看自检”恢复当前页报告。
6. “导出脱敏诊断”仅输出字段编号、状态、原因和计数，剔除标签、值、URL、源资料和密钥。字段编号可与本页结果对应。

仅覆盖当前消息所到达的表单框架。报告在页面内存中，刷新后失效。填写任务取消或异常时不声称自检完成。自检只观察，不点击暂存、提交或真实性声明。内存中短暂保留填写前与填写后值以便回读比较，不写入诊断文件。

限制：两次短时回读无法覆盖无限延迟的站点校验；未识别的组件错误和服务器端校验需要人工确认。当前没有刷新后的保存对照功能，报告明确标记网站暂存未验证。已验证表示本次填写确认与回读稳定，不能作为资料真实性或最终提交合法性的判断。

测试：self-check-regression.cjs 检查正常、回退、校验错误、控件替换、跳过手填、报告读取与定位；self-check-popup-regression.cjs 检查安全文本、定位消息与导出脱敏；海信基准包含自检计数断言。Chrome 实页新版验收仍待重载后执行。
