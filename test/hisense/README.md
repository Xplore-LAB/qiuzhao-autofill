# 海信快速验收基准

## 每次改代码后的用法

在本目录第一次运行 `npm install` 安装隔离测试依赖，随后运行 `npm test`。

无需重新加载扩展、无需登录海信、无需密钥。执行的填写逻辑是当前 `../../content/content.js`，chrome.storage 和消息通道仅在测试页面中模拟，不读取安装扩展中的用户资料。

结果在 `reports/latest.html` 和 `reports/latest.json`。报告包含版本、源码 SHA256、逐项预期与实际、耗时、前后场景通过状态变化。每次保留带时间的 JSON；正常退出码为 0，失败为 1。交互场景失败时输出 DOM 快照。测试数据全部为固定演示资料。

如环境已有 jsdom，可指定 `QIUZHAO_JSDOM=/绝对路径/node_modules/jsdom node run.cjs`，无需重复安装。测试依赖不属于扩展运行依赖，打包插件时应排除 test、node_modules 和 reports。

## 真实浏览器验收台

运行 `npm run serve`，在 Chrome 打开 `http://127.0.0.1:8766/`，点击“运行全部场景”。每个场景在独立 iframe 中加载当前填写源码；刷新重跑即可，不需要重载扩展。页面汇总结果并可下载 JSON。停止服务使用 Ctrl+C。

服务只监听本机，白名单限定必要的测试 HTML、JS、CSS 和填写源码，不提供资料 JSON、密钥、目录浏览或任意路径读取。响应禁用缓存。

本次自动执行证据来自 jsdom。真实浏览器验收台的 Chrome 全流程、截图留证尚待验证。此前浏览器工具访问本地页面遇到安全限制，不通过其他地址、浏览器控制技术或修改安全设置绕过。验收台已准备好供正常浏览器访问，不能将 DOM 测试标为 Chrome 通过。

## 第一批场景和验收条件

| 场景 | 复现行为 | 验收 |
| --- | --- | --- |
| 政治面貌搜索 | 主框和弹层各有输入框，目标最初未渲染，搜索后延迟出现 | 搜索写入弹层；DOM 与模型都为群众 |
| 民族确认选择 | SVG 内部监听，延迟选中，二次确认 | 点击到内部监听、选中后确认、模型与页面均落值 |
| 籍贯三级联动 | 省、市逐级加载，末级图标选择与确认 | 展开顺序正确，只提交市南区完整路径 |
| 选项不存在 | 搜索无结果 | 保持空白，失败计数正确，下一字段继续 |
| 提交后回退 | 有选中状态但确认后不接受值 | 不计入成功，仍为空，弹层清理 |
| 教育、语言、项目、实习、获奖、研究 | 2/2/2/2/3/2 条记录 | 每类所有字段数组与预期一致，再执行不增行、不改值 |
| 综合日期与控件 | 原有综合表单夹具，原生和模拟自定义控件 | 复用原断言，不作为完整海信日历实现的证据 |
| 异步选择 | 延迟弹层、延迟回写 | 等待真实落值，统计与最终控件状态一致 |
| 模拟暂存与恢复 | 从内部模型保存，清空显示后恢复 | 保存内容和恢复后值均匹配，禁止插件点击提交 |

新增交互场景每组 18 项断言（包含 v1.12.0 自检计数）；重复区块覆盖 24 类字段数组及幂等性断言。仍需补齐真实日历 DOM、滚动虚拟列表无搜索模式、页面动态条件字段、文件上传和真实保存。这是首批海信行为基准，非海信整站镜像。

## 证明测试能抓住旧缺陷

运行 `node prove-regressions.cjs`（同样支持 QIUZHAO_JSDOM）。仅在内存中分别恢复旧的搜索框顺序与地区外层选择器，要求相应字段断言失败。生产源码不会被修改。这项测试通过表示旧缺陷被成功检出。

## 采集与复现边界

根据前轮海信实页 DOM 观察复现 Phoenix 类名、层级和事件约束，未复制整站脚本、账号信息或用户填写值。真实站点源 HTML 无法包含全部动态行为。以后每发现一个实页缺陷，先记录字段标签、弹层前后结构、交互步骤和预期，再增加最小失败夹具，最后修改填写源码。

jsdom 模拟尺寸，不能验证实际布局、滚动、可信事件、扩展隔离世界或服务端持久化。本地浏览器页面也模拟扩展消息和网站保存，发布前还需使用真实扩展在海信上抽查，并单独验证暂存恢复。AI 当前关闭；模型相关测试应另建固定响应基准和真实 API 抽样，两类结果分开记录。
