## 当前版本：1.16.12-dev（跨站字段补齐与下拉提速）

点击扩展图标打开标签页专属侧栏，支持窄宽度显示；需要支持 sidePanel.open 的浏览器（Chrome 116+）。新增填写过程、分阶段耗时、待核对项定位，以及下拉选择后的关闭和核对。已有内容默认保留，不自动保存或提交。

**首次使用**：加载扩展后，点击侧栏的“管理资料”，选择 PDF 简历即可自动本地解析，核对后应用资料；无需 API 密钥，也可手动填写。姓名、手机号、邮箱至少保存一项后即可使用侧栏填写，未提供的字段会保持空白。仓库不包含个人资料，也不会自动使用示例身份填表。更新代码后重新加载扩展并刷新招聘网页。

**可选默认文件**：需要用文件维护资料时，将 `content/default-profile.example.json` 复制为 `content/个人资料.json` 并替换示例内容。文件内容发生变化时会更新已保存资料，并保留更新前的恢复记录；文件未变化时保留管理页修改，删除文件也不会清空已保存资料。文件格式错误时会提示修正，不会使用示例数据代替。此文件已忽略，切勿提交真实简历或 API 密钥。

浏览器插件（Chrome / Edge，Manifest V3）。在秋招网申页面优先使用本地规则识别字段，并可选择启用 AI 识别剩余空白字段。

## 功能特性

1. 常用网申预置字段 + 自定义字段 + 学习式映射
2. 四层识别优先级：站点规则（按域名精确映射）> 内置别名库 > 自定义字段 > 学习记录
3. 双触发方式
   - 手动：弹窗按钮 / 网页右键菜单「填充网申表单」/ 快捷键 `Alt+F`
   - 自动：弹窗里打开「自动填充」开关后，打开网申页面即自动填空白字段，动态加载的表单（SPA、点击「添加教育经历」后新增的行）也会补填
4. 安全默认：只填空白字段，不覆盖已手动填写的内容（可在弹窗勾选「覆盖非空字段」）
5. 兼容性设计
   - 字段识别多路信号：`label[for]`、label 包裹、`aria-label`、`aria-labelledby`、placeholder、表单容器标题、前一个兄弟节点、表格前一格、`name`/`id` 属性
   - 中英文别名库 + 正则模式分级打分，取最优匹配
   - 排除规则防误填：「紧急联系人电话」不会被手机号命中，「现居住地」不会被期望工作地点命中
   - 原生与自定义下拉均可用同义词表匹配选项（「硕士」可匹配「硕士研究生 / 全日制研究生」等写法）
   - 支持原生单选组及 Phoenix、Ant Design、Element、Arco、iView 常见自定义单选组
   - 支持海信所用 Beisen Phoenix 选择层、普通下拉、民族选择和日期输入
   - 省市级联：期望工作地点写「广东 深圳」会按序填入两个下拉
   - React/Vue 受控组件兼容：原生 setter 赋值后派发 input/change 事件
6. 学习式映射（v1.1）：你手动填写过的字段会被记住（标签 → 值），下次遇到同类标签自动填，跨网站生效；在弹窗「自定义」标签页可查看、单条删除、一键清空
7. 站点规则（v1.1）：遇到顽固识别不了的网站，在弹窗里为当前域名配置「匹配词 → 资料字段」的精确映射，优先级最高
8. 未识别字段导出（v1.1）：右键菜单「复制未识别字段清单」，把当前页所有插件不认识的字段复制到剪贴板，便于反馈补充规则
9. 隐私：个人资料值、原始资料与 API 密钥存于 `chrome.storage.local`。只有用户点击“AI 提取并预览”或启用 AI 补填时，插件才会把原始资料文本、资料字段值、页面字段名称与候选选项发送给所选模型。API 密钥不会进入导出备份
10. 空白原因报告（v1.3）：填充后区分「资料未填写」「控件仍为空」「字段尚未支持」，便于快速补资料或修规则
11. 教育经历明细（v1.3）：学校、专业、开始时间、结束时间、学历、学位、培养方式可单独配置；留空时可复用毕业院校、专业、毕业时间等资料
12. 自动完成候选（v1.3）：学校等搜索型输入框会在手动填充时尝试选择名称一致的候选项
13. 富文本输入（v1.3）：支持填写使用 `contenteditable` 实现的自我介绍、个人简介等编辑区域
14. AI 补填（v1.4）：支持 OpenAI 兼容 Chat Completions 和 Responses 协议，本地规则完成后再识别剩余空白字段
15. 厂商快速配置（v1.5.1）：内置 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、阿里云百炼与通义千问、Kimi、硅基流动、MiniMax，并保留自定义兼容接口
16. 动态模型列表（v1.5）：粘贴密钥后调用厂商模型列表接口，只展示可用于文本生成的模型，自动选择首个可用模型并启用 AI
17. 稳定连接（v1.5.2）：内置厂商使用精确 API 域名权限，避免授权提示关闭弹窗后中断模型读取；自定义接口仍按需申请权限
18. 可见诊断（v1.5.3）：连接状态固定显示在按钮下方，区分处理中、成功和失败；MiniMax 提供国内与国际两个区域入口
19. 密钥清理（v1.5.4）：自动移除 Bearer 前缀、引号和不可见字符，可从带说明文字的复制内容中提取有效密钥
20. AI 响应兼容（v1.5.5）：可从思考文本、Markdown 和附加说明中提取完整 JSON，并忽略“请输入”等通用自定义字段名
21. 复杂控件适配（v1.6）：支持原生与自定义单选、普通下拉、搜索下拉、级联选择、日历、月份和日期时间输入；页面最终显示目标值后才计入已填
22. 海信与重复经历适配（v1.7）：修复 Phoenix 单选校验和“非农户口”选项；支持项目、实习字段与月份选择器；忽略搜索框和通用“请输入”污染记录
23. 完整履历字段（v1.8）：补充语言能力、教育属性、获奖情况、研究成果和附加问答，使用区块上下文区分重复的名称、时间与描述字段
24. 批量履历（v1.9）：教育、语言、项目、实习、奖项、研究成果均支持多条记录。可粘贴分段文本或 JSON 数组，插件会按数量点击对应的“添加经历”按钮并依次填写
25. 原始资料提取（v1.9）：支持导入 `.docx`、`.xlsx`、`.xls`、`.csv`、`.json`、`.txt`、`.md`，先在浏览器本地解析文字和表格，再由已配置模型提取到个人资料
26. 严格本地匹配（v1.9）：高置信字段由本地规则直接填写，分数并列或语义不明确的字段留给 AI 结合原始资料与候选选项判断
27. 页面总览（v1.10）：点击填充后先统计页面字段、规则可填项、AI 待判断项和多条资料计划，再执行填写
28. 重复区块增强（v1.10）：通过每个“添加经历”按钮定位对应区块，按资料条数添加并填写教育、语言、项目、实习、获奖与奖励、研究情况与成果
29. 获奖与研究别名（v1.10）：兼容奖励名称、荣誉名称、颁发时间、研究项目、课题、论文、专利、研究内容等常见写法
30. AI 页面总览（v1.10）：启用 AI 后，模型会在填写前复核字段语义、模糊项和重复区块；仅发送页面字段标签、控件类型和候选选项，不发送个人资料值
31. 选项验证与统计（v1.10.1）：适配海信下拉框的选中显示节点、单选圆圈点击和延迟更新；同名字段按实际次数统计，同时区分本次填写数与页面当前已填写数。
32. 地区级联（v1.10.2）：识别海信地区选择器，按完整省市区路径逐级展开、选择末级并确认。资料缺少末级或选项不存在时保留空白，关闭当前弹层后继续。
33. 文档资料：PDF 导入后自动进行本地结构化解析；其他格式可点击“本地解析并预览”。姓名、联系方式及多段教育、实习、项目、奖项先进入差异预览，并展示原文依据。复杂格式可主动使用 AI 辅助。原始文档无需在每次填表时重新解析。
34. 资料管理：新增“我的简历”首页和大窗口，支持即时保存、差异预览、上次批量更新前的恢复记录、资料备份恢复和同字段并发修改提示。详细流程见 [USER-FLOW.md](USER-FLOW.md)。

## AI 配置

1. 默认关闭，未配置时完全使用本地规则
2. 在扩展弹窗的 `AI` 标签页选择模型厂商
3. 粘贴 API 密钥，点击“连接并获取模型”
4. 扩展会验证密钥、读取模型列表、自动选择首个可用文本模型并启用 AI
5. 可以在“可用模型”下拉框中随时切换模型
6. 每个厂商的密钥独立保存在 `aiSecrets.keys`，导出 JSON 时不会包含密钥
7. 内置厂商只声明各自的精确 API 域名，自定义接口按需申请访问权限，关闭自定义 AI 时会撤销该权限
8. 自定义接口应使用 HTTPS，本机 `localhost` 或 `127.0.0.1` 可以使用 HTTP
9. “从备份恢复资料”仅合并勾选的个人资料，不改变当前 AI 配置；新安装或换电脑后需重新配置模型和密钥

## 批量经历与原始资料

1. 在“教育背景”“项目实习”“语言成果”页可粘贴多条记录
2. 每条记录用空行分隔，每行使用 `字段：内容`，也可以直接粘贴 JSON 数组
3. `时间：2024-07 至 2024-09` 会自动拆分为开始时间和结束时间
4. 在“我的简历”页选择 PDF 文本简历，自动本地解析后核对姓名、联系方式和多段经历，点击“应用勾选的变化”，再返回招聘网页填写。Word、Excel 或文本可点击“本地解析并预览”；复杂格式可配置 AI 后主动提取。已有内容的替换和清空默认不勾选。解析范围与验证见 [PDF 导入说明](docs/PDF-IMPORT.md)
5. 页面存在多段经历时，插件按原始顺序新增并填入。单次每类最多处理 20 条记录

## 敏感操作防护

- 密码、验证码、支付、银行卡、文件上传类控件一律不填充、不学习、不导出
- 含密码框的表单（登录/注册）内的任何控件不填充、不学习
- 自动模式遇到可见密码框（登录页）时整页跳过，并在弹窗里说明原因
- 原生输入只派发 input/change 事件；手动填充自定义下拉或单选时，只点击已识别的控件和选项
- 永远不点击提交、预览、暂存、上传等页面操作按钮
- 自动填充会先判断页面是否具有招聘/网申特征，并跳过需要点击的自定义控件

## 与浏览器自带「记住填写信息」的差别

| 能力 | 浏览器自带自动填充 | 本插件 |
| --- | --- | --- |
| 中文表单识别 | 常失败（按英文 name 属性记忆） | 中英文别名 + 多路信号打分 |
| 跨网站复用 | 同一网站同一字段才提示 | 学习记录按标签匹配，换网站也能填 |
| 下拉/单选 | 基本不支持 | 原生与常见自定义组件均支持同义词匹配、单选组、省市级联 |
| 填写方式 | 弹下拉列表需手动选择 | 直接填入，绿色光圈反馈，无需交互 |
| 误覆盖 | 可能覆盖已填内容 | 默认只填空白 |
| 登录页安全 | 会提示保存密码 | 整页跳过，密码类一律不碰 |
| 数据归属 | 绑定浏览器账号同步 | 纯本地，可导出 JSON 随身携带 |

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（qiuzhao-autofill 文件夹）
4. （可选）到 `chrome://extensions/shortcuts` 查看或修改快捷键
5. 更新前先导出资料备份；在同一扩展目录更新源码后点「重新加载」，再刷新招聘页面。不要先卸载旧扩展；换目录、重装或换浏览器配置后，按 [用户全流程](USER-FLOW.md) 恢复资料

## 使用

1. 打开插件的“我的简历”，点“填写 / 修改资料”；长简历可点“在大窗口管理”。填完等底部显示“已保存”
2. 返回招聘页面，点击“识别并检查表单”，核对字段数量与经历后再点“确认填写并自检”；侧栏始终只填空白。如果有多个嵌入表单，先选择本次区域。页面跳转、展开新的表单或修改资料后，重新检查再填写。右键和 `Alt+F` 仍为保留已有输入的快捷入口；快捷键发现多个表单时提示改用侧栏选择
3. 填充成功的字段会短暂显示薄荷绿描边，页面右上角有结果提示
4. 遇到插件不认识的字段：直接手动填一次，插件会学习；或到「自定义」标签页添加字段；顽固网站用「站点规则」
5. 遇到识别失败：右键「复制未识别字段清单」，把剪贴板内容发给开发者即可精准补充规则

6. 打开“收藏当前岗位”，点“读取岗位信息”，核对名称、公司、地点、截止日期和链接后保存。优先识别 JobPosting 结构化数据，缺少数据时只提供页面标题，不猜测公司与岗位描述。在“投递记录”中管理状态、备注和导出；只有本人勾选确认正式提交，才会标记为“已投递”。

首次使用、后续更新、异常处理和换机操作详见 [用户全流程](USER-FLOW.md)。PDF 文本简历可在插件内读取，扫描件暂不支持 OCR；附件简历仍需在招聘网站手动上传，插件中的资料保存与网站保存是两步。

建议先使用固定演示资料在 `test/demo-form.html` 验证，再进入真实网申站。

## 支持字段

| 分类 | 字段 |
| --- | --- |
| 基本信息 | 姓名、姓/名（分开的表单）、性别、出生年月、政治面貌、民族、户籍/籍贯、户口性质、婚姻状况、身高、体重、身份证号、手机号、邮箱、微信号 |
| 教育背景 | 毕业院校、专业、学历/学位（专/本/硕/博）、毕业时间、应届/往届、英语等级、英语成绩、计算机等级、GPA/绩点、专业排名、最高学历学科、本科学科、多段教育经历 |
| 求职意向 | 期望工作地点（支持省市两级）、期望职位、期望薪资 |
| 校招补充 | 期望面试站点、推荐码、其他外语、奖学金、优秀毕业生、项目或实习数量、学生干部、竞赛奖项、招聘信息来源 |
| 履历与成果 | 多段语言能力、项目经历、实习经历、获奖情况、研究成果 |
| 补充信息 | 个人主页/GitHub、自我介绍、公司分配与外派等附加问答 |
| 自定义 | 任意键值对，按字段名与网页标签的包含关系匹配 |
| 学习记录 | 自动记录手填过的「标签 → 值」，上限 120 条按时间淘汰 |

## 已知限制

- 密码、验证码、文件上传、复选框一律不碰（安全设计，非缺陷）
- 嵌在 iframe 里的表单：侧栏按区域识别、选择、填写和核验，不会向所有 frame 广播填写。受浏览器权限限制而未注入脚本的区域仍需手动处理。旧管理页的快捷填写只处理主页面，嵌入区域请使用侧栏
- 尚未覆盖的自绘控件仍需手动填写，可通过「复制未识别字段清单」反馈
- 招聘网站的新增经历按钮必须有可识别的“添加教育经历”等文字；若按钮点击后没有生成新表单行，插件会停止继续添加并在结果中保留空项
- 期望薪资等选项跨度大的下拉可能匹配失败，会在结果里提示「无法匹配」
- Firefox 需另行适配：加 `browser_specific_settings`、图标，API 层面基本兼容

## 目录结构

```
qiuzhao-autofill/
├── manifest.json           # MV3 清单
├── background/service-worker.js  # 右键菜单 + 快捷键转发
├── content/content.js      # 字段识别 + 填充 + 学习 + 站点规则 + 敏感防护（核心）
├── popup/                  # 资料编辑 + 学习记录 + 站点规则 + 触发入口
│   ├── popup.html / popup.css / popup.js
├── vendor/                 # Word 与 Excel 本地解析组件及许可证
└── test/                   # 静态、AI、常见控件与多段履历回归测试
```
