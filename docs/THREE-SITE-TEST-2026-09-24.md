# 快手、小鹏、海信：速度与填写效果实测

测试日期：2026-09-24（北京时间）。源码提交：`f14c4b8`。实际加载扩展与内容脚本：`1.16.13-dev`。

**结论：三个招聘网站均完成本轮模拟资料自动填写与最终核验；不能据此宣称整份申请已完成或所有场景完全兼容。** 小鹏已识别的 61 个字段无空白；快手与海信分别保留 1、3 个缺资料或无法可靠确定的字段。整页总耗时约 27–34 秒，尚未达到十几秒目标。

总耗时取运行日志 `durationMs`；阶段耗时取侧栏显示，四舍五入至 0.1 秒。计时从确认填写到最终自检完成，包含动态添加经历，不包含人工打开页面、切换资料、只读预检和导出日志的时间。保留 5 秒迟到回退观察。

每站本轮各一次完整运行，均为 `finished` / `final`，不是多轮均值或 p95。三个页面字段数量、资料与组件不同，不以表格直接比较网站性能。计时期间没有运行本地浏览器回归测试。

“核验通过”表示插件最终回读与本轮目标值一致，不等于服务端已接受或保存；“非空”还包含网站已有内容，不能当成自动填写正确率。附件槽、未发现的控件及折叠/条件分支不属于该分母。

## 各站填写效果与边界

### 快手

- 初始预检 26 个控件：2 个已有网站默认值，11 个本地规则候选，13 个其余空白。默认教育 1 行，其余经历从 0 行自动添加。
- 最终 83 个已识别控件：80 项核验通过，保留电话区号与证件类型两个默认选项，证件号留空。未使用已知无效证件占位值反复尝试。
- 共 16 条记录：教育、实习、项目、语言、IT 技能、竞赛各 2 条，论文、技能证书、其他荣誉、作品各 1 条。
- 切换至日志再返回页面后，联系人姓名和电话对应正确，教育/实习/项目日期、学院/实验室/导师、论文渠道、技能证书、竞赛和作品值仍保持。未手动补填来提高统计。
- 侧栏 5 项待核对：1 个缺资料证件号、2 个保留默认选项、2 个未找到对应控件的项目链接。项目链接是资料中的额外字段，不是页面上发现的两个空输入框。

### 小鹏

- 初始预检 15 个控件、0 个已有内容、9 个规则候选。默认教育 1 行，其余目标经历从 0 行自动添加。
- 最终 61 个已识别可填写字段全部核验通过、无空白。共 12 条记录：教育 3 条，实习、项目、获奖、语言各 2 条，作品 1 条。
- UI 复核学校、所在城市、期望城市、日期范围、获奖年份和语言程度均显示目标值；保留网站原有“没有工作经历”。
- 侧栏另有 38 项：5 个资料区块未在页面发现、33 个记录字段未找到对应控件。它们与已识别的 61 个控件不是同一个统计范围，不能算成 38 个可见空白，也不能据此保证所有隐藏字段均已覆盖。

### 海信

- 原有账号手机号保留；最终 106 个已识别控件，102 项核验通过、103 项非空、3 项空白。
- 3 项空白：证件号码、高中学科、高中学位，按用户允许的“不确定就留空”策略处理。
- 共 12 条记录：教育 3 条，语言、项目、实习、获奖各 2 条，研究成果 1 条。
- 切换标签再返回后，完整三级籍贯、招聘来源、三条学校和教育年月范围仍保持。
- 侧栏 28 项待核对：原有手机号 1 项、上述空白 3 项、未发现的资料区块 5 项、未找到对应控件的记录字段 19 项。
- 与上一轮同版本实测 30.043 秒 / 102 项一致，本轮为 29.981 秒 / 102 项。这两次结果不能推导任意机器、网络或资料下的性能保证。

## 测试方法与资料

使用同一个 Google Chrome for Testing `151.0.7922.34`，三站均新开简历编辑标签页，保留历史结果页；本地规则模式，AI 关闭，仅填空白。海信在侧栏启动填写后由 Agent 跟踪；小鹏和快手由 Agent 经预检、确认填写启动。日志均确认加载 `1.16.13-dev`。

- 海信沿用 [两站模拟资料](../test/fixtures/xpeng-hisense-demo-profile.json)，招聘来源为已观察到的完整选项，证件号为空。
- 小鹏经管理页导入 [小鹏模拟资料](../test/fixtures/xpeng-demo-profile.json)，应用 7 项变化，取消导入无效证件号。
- 快手经管理页导入 [快手完整模拟资料](../test/fixtures/kuaishou-full-demo-profile.json)，应用 6 项变化，证件号继续为空。资料更新采用合并方式，保留了小鹏资料中两条项目的额外 `projectUrl`，因快手页面没有对应输入而提示待核对；未把当前浏览器资料说成与文件逐键完全相同。
- 本轮没有上传附件、点击网站保存/暂存/完成或提交申请。浏览器当前资料仍是模拟测试资料，不代表用户本人；正式使用前应切换为本人核实的简历。

## 后续优先项

1. 继续缩短实际填写阶段；同时保留回退核验。当前三站整页均未达到十几秒，不将 17.0 秒的小鹏“填写阶段”宣传为整页速度。
2. 将“本页面未提供的资料字段”与“已发现但填写失败的控件”在结果界面分开呈现，减少 38/28 项待核对带来的误解。
3. 另行验证有效本人资料、附件、网站保存恢复与正式投递；复杂条件字段、乱序既有经历和其他企业租户仍按 [覆盖清单](WEBSITE-COVERAGE.md) 推进。
