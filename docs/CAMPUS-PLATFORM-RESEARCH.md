## 可复用的实现与缺口

| 场景 | 已有能力 / 本轮改进 | 下一步需要的证据 |
| --- | --- | --- |
| 文本、单选、下拉、日期 | 现有原生、Ant、UD、Phoenix 驱动；本轮 UD 改为按弹层出现、选中和关闭状态推进 | 每站真实失焦与重渲染行为；未知组件不能只按外观套用 |
| 相同语义不同名称 | 新增“实习经验／项目经验”，实习区块内识别“工作职责” | 更复杂区块标题、卡片与折叠结构；正式工作与实习保持独立 |
| 默认零条或一条经历 | 依资料条数补足，逐条核对，不重复添加；新合成案例两种初始状态都通过 | 真实租户的行数上限、异步新增、已有乱序记录 |
| 学校、专业远程联想 | 已有候选匹配与关闭处理，海信异步修复仍待实页终验 | 精确候选、无结果、仅允许词库选项、允许自由输入四种情况分别记录 |
| 条件字段、折叠、多步骤 | 已有可见控件扫描，但本轮未新增完整跨步骤覆盖 | 选择后新增字段、隐藏区块与下一页；初次扫描数不能作为全表分母 |
| 自定义问答 | 已有自定义字段、站点映射和可选 AI；明确资料优先 | 企业特有问题需要本人真实答案；不能为了非空率编造薪资、关系或资格 |
| 附件与图片 | PDF 可先本地解析并经核对入资料库 | 插件网站自动上传、头像裁剪、成绩单匹配仍未实现；不能混同本地导入和网站上传 |

判断能否覆盖时，先看控件行为和数据含义，再看公司名称。一个新增公司如果复用已验证组件，大部分基础字段可能复用驱动；这只是工程预期，仍需该租户实页验证。

## 速度与完整性的验收口径

- **总耗时**：从触发填写到最终逐项核验结束，包括发现控件、添加经历和迟到回退观察；登录、人工补资料、附件传输与正式提交另外统计。当前 10–15 秒目标用于资料齐备的典型表单，不能承诺任意长表或慢网络。
- **正确率**：按人工盘点的适用字段和所有目标记录核对，不能仅看非空。必填/选填、缺资料、未发现、控件失败、不适用、已有待核对分别记录；附件独立统计。
- **重复性**：再次运行不重复增加记录，不改写已有正确值；正式工作和实习不能互填。
- **基准环境**：同一合成页、同一固定资料、同一浏览器，分别测默认 0 行和 1 行；报告首次整页填写。多次采样与真实慢网数据不足前不报 p95 或普适 SLA。

1.16.12 本地 39 项控件整页：默认 0 行 **19.044→11.319 秒**，默认 1 行 **19.081→11.315 秒**；前后均 39 项终验通过，包含 10 条经历/作品等记录和最终观察。每种状态前后各一次，不是线上平均值。详情和复现命令见[提速与覆盖验证记录](../test/issues/2026-09-24-campus-coverage-speed.md)。
