更新日期：2026-09-24。用途：确定下一批适配目标、复用控件测试、积累逐站证据。**这是覆盖工作台，不是“已支持网站”宣传清单。**

本轮快手 1.16.1-dev 已完成固定模拟资料全栏目落值、16 条经历和重复运行验证：83 控件非空、80 项终验通过、模拟身份证校验拒绝、2 个默认选项保留。附件选择器上传完成，插件自动上传、整页保存与正式投递仍未验证。详见 [本轮实页记录](../test/issues/2026-09-24-kuaishou-live.md)。

## 1. 统一验收口径

遵循 [开发闭环](../FEEDBACK-LOOP.md)。每个案例分别记录以下层级，不以一个“通过”代替：

| 层级 | 可以证明什么 | 不能证明什么 |
| --- | --- | --- |
| 已观察 / 待证据 | 页面结构或故障确实出现，或明确缺少访问/日志条件 | 已复现、已修复 |
| 模拟测试通过 | 固定演示资料在最小 DOM/组件行为夹具中符合预期 | 招聘实页适配、真实账号保存 |
| 本地真实扩展通过 | MV3 内容脚本、侧栏、消息与存储在隔离浏览器正常协作 | 外部网站控件与后端接受数据 |
| 实页落值已验证 | 指定版本在指定页面正确填写，失焦和后续交互后保持 | 所有同类网站通过、服务端保存、正式投递 |
| 网站保存已验证 | 网站明确保存成功，按授权重新进入后正确恢复 | 已申请岗位 |
| 正式投递已验证 | 经授权提交后有可核实的申请状态或回执 | 其他岗位也已投递 |

每轮同时记 `目标字段数 / 已发现字段数 / 正确终验数 / 空白数 / 已有待核对数 / 不适用数`，分别列出重复记录数和附件数。动态新增前后的统计口径不能混用；“非空”不等于正确，未发现的字段也不能从分母消失。必填和选填分别统计；资料不足、控件失败、类别歧义和主动停止分别报告。

“全表填完”的验收条件：先人工盘点页面所有区块及条件展开内容，再核对每条目标记录的每个适用字段、枚举选择、日期和附件；没有静默遗漏、串行或串字段。当前用户授权模拟数据填表，正式保存/提交沿用独立授权边界，不为完成率自动执行。

## 4. 日期快速定位矩阵

不将逐日翻页作为默认策略。按页面能力依次选：可编辑输入 → 年/月选择面板 → 有界月/年导航。每一步都核对真实面板状态，不能只修改显示文字。日期范围必须作为一组事务完成，不能把结束日临时预览当原有输入而跳过。

| 编号 / 优先级 | 场景 | 验收目标 | 当前证据 |
| --- | --- | --- | --- |
| D01 / P1 | 可编辑 `date`、`month`、日期文本 | 直接输入规范值并派发正确事件；失焦后精确回读 | 本地日期能力与回归；按站点补实页证据 |
| D02 / P0 | 只读 Ant 单日期，生日跨数十年 | 优先切换年面板定位年份，再定位月份和日期；记录总点击数与耗时，禁止按天遍历 | 本地 2026-09→2000-02-29 行为夹具从 34 次降至 6 次；实页生日 2000-01-01 已落值。实页点击数未测 |
| D03 / P0 | Ant 双日历日期范围 | 按目标年/月快速定位；只点可见导航；两端精确且顺序正确；后续操作不回退 | 1.16.1 快手六组范围、12 个端点均正确，观察到年月面板定位，后续运行保持 |
| D04 / P1 | 月份范围、至今、只有毕业年月 | 遵守控件粒度；“至今”按实际选项处理；月份转日期的默认日明确记录 | 历史快手年月资料在日期控件中展开为当月 01 日；不推定所有站点相同 |

统一使用至少两条内容明显不同的演示记录（学校、公司、名称、时间、描述都能区分），验证“新增数量正确”和“每条填写正确”两件事。不能仅检查新增行数。

## 7. 对标工具：WonderCV 与 OfferLink

两者是用户指定的投递辅助对标工具，**不是本表中的招聘网站案例**。对标使用同一站点、同一演示资料和同一统计口径，不直接引用广告覆盖数作为我们已实现的范围。

| 对标对象 | 入口 / 来源状态 | 待核实的比较项目 |
| --- | --- | --- |
