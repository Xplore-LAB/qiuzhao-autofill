# PDF 简历导入（1.16.11-dev）

首次使用路径：管理资料 → 选择 PDF 简历 → 自动本地解析 → 核对并应用 → 返回招聘网页检查与填写。不需要 API 密钥，不会自动发送简历给模型。

## 本地解析范围

| 内容 | 当前支持 | 核对重点 |
| --- | --- | --- |
| 基本资料 | 姓名、手机、邮箱，以及明确标注的出生日期、性别、政治面貌、民族、户籍、微信、主页和求职意向 | 首行姓名属于候选；联系方式有冲突时留空；不推断身份证或意愿 |
| 教育经历 | 常见中英文栏目、学校、专业、学历、起止日期，多条记录 | 学校独立行、带日期标题、键值标签；只有能确定唯一最高学历时生成单项毕业院校等资料 |
| 实习、项目 | 多段标题、起止日期、角色、描述；标题和日期可分行 | 核对每段归属；正式工作经历不冒充实习 |
| 获奖 | 带标签的名称、日期、级别、描述，或日期开头的奖项行 | 未识别奖项保留在原文，不编造分类 |
| 语言与简介 | 明确的 CET 等级/分数、自我评价栏目 | 未支持的技能、语言与复杂表格仍需补充或主动使用 AI |

日期保留原文精度（年、年月或年月日）；明确的“至今 / Present”可作为结束时间。无效日期、起止倒置及互相冲突的联系方式不会强行写入。

PDF.js 只提取文本，规则解析器将文本映射到已有资料字段。每个候选字段/经历组显示原文依据；可展开完整原文检查遗漏。解析器不能保证任意模板、跨栏、表格、断字或缺少栏目标题的简历完整还原。扫描件没有文本层时提示先 OCR；当前没有内置 OCR。

Word、Excel、文本文件沿用本地读取入口，读完可点击“本地解析并预览”；复杂材料可配置模型、处理当前草稿后，主动点击“AI 提取并预览”。本地解析不调用模型，AI 路径继续保留用户主动触发边界。

## 保存与恢复

- 导入先生成草稿，已保存资料不会被解析结果直接替换。新字段默认选中，已有字段与整组经历替换需要勾选。
- 应用后，结构化数组直接供现有重复经历填充器使用，支持网站初始零行或一行时自动补行。网页填写仍需用户触发，不自动保存或提交网站。
- 草稿及原文依据保存在本机，关闭管理页后可继续核对。应用前保留一次恢复记录。
- 有草稿时拒绝导入另一文件；读取失败保留上次成功的原文。解析进行时禁用重复导入、清除与其他提取入口。
- 限制保持 20MB / 50 页 / 30 万字符 / PDF 读取 30 秒。原始简历、恢复记录及草稿均不进入 Git 仓库。

## 验证证据

`test/resume-parser-regression.cjs` 使用固定合成中英文文本，覆盖基本资料、多段经历、原文依据、联系方式歧义、无效日期、标题与日期分行及不支持栏目。

`test/pdf-import-regression.cjs` 在隔离 Chromium 中加载真实 MV3 扩展、PDF.js worker、存储和消息接口，测试真实合成 PDF 文件导入：

1. 两页中文/英文文本被读取，生成两段教育、两段实习、两段项目及两项奖励的草稿。
2. 已有姓名默认不替换，重复导入被阻止；重开仍保留草稿和依据；应用后资料实际写入。
3. 已保存资料填入测试网申的基本字段，教育初始一行、项目初始零行均补为两行并逐项校验。
4. 测试期间没有外网请求，没有模型调用或表单提交；扫描件、损坏/空文件、体积/页数/字符/超时限制及失败恢复覆盖。

这是本地真实扩展与合成表单验证，未证明任意用户 PDF 或任意招聘网站都能完整解析/填写。当前用户测试浏览器仍锁屏，未在该浏览器更新到 1.16.11；已安装版本与本轮源码版本应分别核对。小鹏历史实页验证和海信待复验状态见 [网站覆盖记录](WEBSITE-COVERAGE.md)。
